AI Privacy and Media Integrity System

TraceAI

TraceAI is an AI-assisted system focused on image provenance, duplicate detection, altered media review, false positive reduction, and lawful evidence support for unauthorised image reuse.

Working technical prototype

What TraceAI Does

TraceAI is being developed to help identify possible visual evidence leads and organise them for human review.

Image provenance and source/context review

Supports review of visual media sources and surrounding context.

Duplicate and near-duplicate detection

Helps review duplicate and near-duplicate visual material.

Altered media review

Supports review of possible altered or modified media items.

False positive reduction

Designed to reduce false positives in media integrity workflows.

Lawful evidence support

Organises possible evidence leads for appropriate lawful review processes.

Privacy-preserving media integrity processes

Focused on responsible, privacy-preserving media integrity workflows.

Current Status

TraceAI is currently at working technical prototype stage and is under active development.

The project is moving toward MVP hardening, cloud deployment, reliability testing, and safer evidence workflow development.

Intellectual Property

Facewipe LTD has filed UK patent application GB2612078.2, titled “Visual Evidence Review System”, relating to TraceAI.

Responsible Use

TraceAI does not make automatic ownership, infringement, identity, or takedown conclusions.

All possible evidence leads require human review.
